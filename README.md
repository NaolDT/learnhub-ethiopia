# LearnHub Ethiopia

Ethiopian digital learning platform built with the MERN stack.

## Three experiences

- **Learn:** course marketplace with video lessons and enrollment
- **Prepare:** Grade 12 university entrance exam preparation (question bank, mock exams, performance analytics)
- **Collaborate:** real-time study rooms with a shared whiteboard and chat

## Structure

- `server/`: Node.js, Express, MongoDB, Socket.IO (API and real-time)
- `client/`: React frontend (built after the backend is complete)

## Status

Phase B0: repository setup.

## Development approach

Built phase by phase. Each phase is tested before the next begins and
committed to `main` using conventional commit messages.
